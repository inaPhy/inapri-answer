加速度

加速度

平均の加速度　\(\overline{a} = \dfrac{\textcolor{#d6362b}{\Delta v}}{\textcolor{#d6362b}{\Delta t}}\)
\(\Delta v = v(t+\Delta t) - v(t)\)
（瞬間の）加速度　\(a = \dfrac{\textcolor{#d6362b}{dv}}{\textcolor{#d6362b}{dt}} = \dfrac{\textcolor{#d6362b}{d^2 r}}{\textcolor{#d6362b}{dt^2}}\)
速度の微分 ＝ 位置の2回微分

ポイント　加速度は「速度が 1 秒あたりどれだけ変化するか」。速度と同じく向きをもつので，右向きを正とすると，左向きの速度や減速は − で表す。\(v\)-\(t\) グラフでは，加速度はグラフの傾き（接線の傾き）になる。

位置・速度・加速度の関係

位置 \(r\) 速度 \(v\) 加速度 \(a\)

ポイント　右へは「\(t\) で微分」，左へは「\(t\) で積分」。積分したときに出てくる積分定数は，\(t = 0\) のときの値（初期条件）で決める。

例題①

直線上を物体が加速度で運動している。この物体の運動について，次の (1)・(2) の平均の加速度を求めよ。ただし，右向きを正とする。

  1. 点Oを右向きに速さ 3.0 m/s で通過し，2.0 s 後に右向きに速さ 9.0 m/s になった。
  2. 点Oを右向きに速さ 24 m/s で通過し，4.0 s 後に左向きに速さ 8.0 m/s になった。
解説

平均の加速度は「速度の変化 ÷ かかった時間」\(\overline{a} = \dfrac{\Delta v}{\Delta t}\)。速度の変化は「あとの速度 − まえの速度」で，右向きを正，左向きを負として計算する。

(1)

まえは右向きに 3.0 m/s（\(+3.0\)），あとは右向きに 9.0 m/s（\(+9.0\)），時間は 2.0 s。

\[ \overline{a} = \frac{9.0 - 3.0}{2.0} = 3.0 \ \text{m/s}^2 \]
\[ \begin{aligned} \overline{a} &= \frac{9.0 - 3.0}{2.0} \\ &= 3.0 \ \text{m/s}^2 \end{aligned} \]

(2)

まえは右向きに 24 m/s（\(+24\)），あとは左向きに 8.0 m/s なので \(-8.0\)。時間は 4.0 s。

\[ \overline{a} = \frac{-8.0 - 24}{4.0} = -8.0 \ \text{m/s}^2 \]
\[ \begin{aligned} \overline{a} &= \frac{-8.0 - 24}{4.0} \\ &= -8.0 \ \text{m/s}^2 \end{aligned} \]

負の符号は，加速度が左向きであることを表す（「左向きに 8.0 m/s²」）。

(1)3.0〔m/s²〕
(2)−8.0〔m/s²〕

例題②

直線上を運動する物体の時刻 \(t\)〔s〕における位置 \(r\)〔m〕，速度 \(v\)〔m/s〕とする。

  1. \(v = t^2 + 1\) で表されるとき，時刻 \(t = 3.0\)〔s〕のときの物体の加速度を求めよ。
  2. \(r = 2t^3 - t^2 + 4\) で表されるとき，時刻 \(t = 3.0\)〔s〕のときの物体の加速度を求めよ。
解説

(1)

加速度は速度を時間で微分したもの（\(a = \dfrac{dv}{dt}\)）。\(t^2\) は \(2t\)，定数 1 は 0 になる。

\[ a = \frac{dv}{dt} = 2t \]
\[ \begin{aligned} a &= \frac{dv}{dt} \\ &= 2t \end{aligned} \]

\(t = 3.0\) を代入して　\(a(3.0) = 2\times 3.0 = 6.0\) m/s²

(2)

位置の式が与えられているので，まず1回微分して速度を求め，もう1回微分して加速度を求める（\(a = \dfrac{d^2 r}{dt^2}\)）。

\[ v = \frac{dr}{dt} = 6t^2 - 2t, \qquad a = \frac{dv}{dt} = 12t - 2 \]
\[ \begin{aligned} v &= \frac{dr}{dt} \\ &= 6t^2 - 2t \\ a &= \frac{dv}{dt} \\ &= 12t - 2 \end{aligned} \]

\(t = 3.0\) を代入して　\(a(3.0) = 12\times 3.0 - 2 = 34\) m/s²

(1)6.0〔m/s²〕
(2)34〔m/s²〕

例題③

直線上を運動する物体の速度 \(v\)〔m/s〕と時刻 \(t\)〔s〕との関係は下図のようになる。

  1. 速度 \(v\) を \(t\) を用いて表せ。
  2. 物体の加速度 \(a\)〔m/s²〕はいくらか。
  3. 物体の位置 \(r\)〔m〕を \(t\) を用いて表せ。ただし，時刻 \(t = 0\)〔s〕における位置を \(r(0) = -6.0\)〔m〕とする。
  4. \(r\)-\(t\)，\(a\)-\(t\) グラフを示せ。
  5. \(t = 1.0\)〜\(2.0\)〔s〕間の移動距離はいくらか。
  6. \(t = 1.0\)〜\(2.0\)〔s〕間の変位はいくらか。
解説

(1)速度の式

グラフは直線なので \(v = (\text{傾き})\,t + (\text{切片})\) の形。\(t = 0\) で \(v = 2.0\)（切片），1 s で 1.0 m/s ずつ増える（傾き 1）。

\[ v = t + 2.0 \]

(2)加速度

加速度は速度の微分（\(v\)-\(t\) グラフの傾き）。

\[ a = \frac{dv}{dt} = 1.0 \ \text{m/s}^2 \]
\[ \begin{aligned} a &= \frac{dv}{dt} \\ &= 1.0 \ \text{m/s}^2 \end{aligned} \]

(3)位置の式

位置は速度を \(t\) で積分すると求まる。

\[ r = \int v\,dt = \int (t + 2)\,dt = \frac{1}{2}t^2 + 2t + C \]
\[ \begin{aligned} r &= \int v\,dt \\ &= \int (t + 2)\,dt \\ &= \frac{1}{2}t^2 + 2t + C \end{aligned} \]

積分定数 \(C\) は \(t = 0\) のときの位置から決める。\(r(0) = -6.0\) なので \(\dfrac{1}{2}\cdot 0^2 + 2\cdot 0 + C = -6.0\)，よって \(C = -6.0\)。

\[ r = \frac{1}{2}t^2 + 2.0t - 6.0 \]

(4)グラフ

\(r\)-\(t\) グラフをかくために平方完成して頂点を求める。

\[ r = \frac{1}{2}(t^2 + 4t) - 6 = \frac{1}{2}(t + 2)^2 - 8 \]
\[ \begin{aligned} r &= \frac{1}{2}(t^2 + 4t) - 6 \\ &= \frac{1}{2}(t + 2)^2 - 8 \end{aligned} \]

頂点 \((-2,\ -8)\) の下に凸の放物線。\(t = 0\) で \(r = -6\)，\(r = 0\) となるのは \(\frac{1}{2}t^2 + 2t - 6 = 0\)，つまり \((t+6)(t-2) = 0\) より \(t = 2\)。\(a\)-\(t\) グラフは \(a = 1.0\)（一定）の水平な直線。

(5)(6)移動距離と変位

(3) の式に \(t = 1\)，\(t = 2\) を代入して，その間の位置を調べる。

\[ r(1) = \frac{1}{2} + 2 - 6 = -3.5 \ \text{m}, \qquad r(2) = 2 + 4 - 6 = 0 \ \text{m} \]
\[ \begin{aligned} r(1) &= \frac{1}{2} + 2 - 6 \\ &= -3.5 \ \text{m} \\ r(2) &= 2 + 4 - 6 \\ &= 0 \ \text{m} \end{aligned} \]

変位は \(r(2) - r(1) = 0 - (-3.5) = 3.5\) m。この間 \(v > 0\) で折り返さないので，移動距離も 3.5 m。

グラフで見ると　\(v\)-\(t\) グラフで \(t = 1.0\)〜\(2.0\) の部分の面積（図の赤い台形）が変位になる：\(\dfrac{(3.0 + 4.0)\times 1.0}{2} = 3.5\) m。

(1)\(v = t + 2.0\)〔m/s〕
(2)\(a = 1.0\)〔m/s²〕
(3)\(r = 0.50t^2 + 2.0t - 6.0\)〔m〕
(4)解説の \(r\)-\(t\)，\(a\)-\(t\) グラフ
(5)3.5〔m〕
(6)3.5〔m〕

練習問題①

直線上を運動する物体の速度 \(v\)〔m/s〕と時刻 \(t\)〔s〕との関係は下図のようになる。

  1. 物体の加速度 \(a\)〔m/s²〕はいくらか。
  2. 物体の位置 \(r\)〔m〕を \(t\) を用いて表せ。ただし，時刻 \(t = 0\)〔s〕における位置を \(r(0) = 3.0\)〔m〕とする。
  3. \(r\)-\(t\) グラフを示せ。
  4. \(t = 0\)〜\(4.0\)〔s〕間の移動距離はいくらか。
  5. \(t = 0\)〜\(4.0\)〔s〕間の変位はいくらか。
解説

(1)加速度

加速度は \(v\)-\(t\) グラフの傾き。\(t = 0\) で 6.0 m/s，\(t = 3.0\) で 0 なので

\[ a = \frac{0 - 6.0}{3.0 - 0} = -2.0 \ \text{m/s}^2 \]
\[ \begin{aligned} a &= \frac{0 - 6.0}{3.0 - 0} \\ &= -2.0 \ \text{m/s}^2 \end{aligned} \]

速度の式は \(v = -2t + 6\)（傾き −2，切片 6）になる。

(2)位置の式

速度の式を \(t\) で積分すると位置になる。

\[ r = \int v\,dt = \int (-2t + 6)\,dt = -t^2 + 6t + C \]
\[ \begin{aligned} r &= \int v\,dt \\ &= \int (-2t + 6)\,dt \\ &= -t^2 + 6t + C \end{aligned} \]

\(r(0) = 3.0\) なので \(C = 3.0\)。よって \(r = -t^2 + 6.0t + 3.0\)。

(3)\(r\)-\(t\) グラフ

平方完成すると \(r = -(t - 3)^2 + 12\)。頂点 \((3,\ 12)\) の上に凸の放物線で，\(t = 0\) で \(r = 3\)（例題③ (4) と同じ手順）。

(4)移動距離

\(t = 3\) s で速度が 0 になり，そこで折り返す（3 s 以降は \(v < 0\) で逆向きに進む）。そこで行きと帰りに分けて考える。

\[ r(0) = 3, \qquad r(3) = -9 + 18 + 3 = 12, \qquad r(4) = -16 + 24 + 3 = 11 \]
\[ \begin{aligned} r(0) &= 3 \\ r(3) &= -9 + 18 + 3 \\ &= 12 \\ r(4) &= -16 + 24 + 3 \\ &= 11 \end{aligned} \]

0〜3 s で \(12 - 3 = 9\) m 進み，3〜4 s で \(12 - 11 = 1\) m もどる。移動距離は \(9 + 1 = 10\) m。

(5)変位

変位は最初と最後の位置の差だけで決まる。

\[ r(4) - r(0) = 11 - 3 = 8.0 \ \text{m} \]
\[ \begin{aligned} r(4) - r(0) &= 11 - 3 \\ &= 8.0 \ \text{m} \end{aligned} \]

グラフで見ると　\(v\)-\(t\) グラフの面積で，\(t\) 軸より上（正）が 9 m，下（負）が 1 m。移動距離は面積をそのまま足して 10 m，変位は符号をつけて足して \(9 - 1 = 8\) m。

(1)\(a = -2.0\)〔m/s²〕
(2)\(r = -t^2 + 6.0t + 3.0\)〔m〕
(3)解説の \(r\)-\(t\) グラフ
(4)10〔m〕
(5)8.0〔m〕

練習問題②

\(x\) 軸上を正の向きに 2.0 m/s² で等加速度直線運動する物体がある。物体の時刻 \(t = 0\)〔s〕での速度は \(v(0) = -6.0\)〔m/s〕であり，位置は \(x(0) = 5.0\)〔m〕である。

  1. 物体の時刻 \(t\)〔s〕での速度 \(v\) を \(t\) を用いて表せ。
  2. 物体の時刻 \(t\)〔s〕での位置 \(x\) を \(t\) を用いて表せ。
  3. 位置 \(x = 0\)〔m〕となる時刻を求めよ。
解説

(1)速度

加速度 \(a = 2.0\)（一定）を \(t\) で積分すると速度になる。

\[ v = \int a\,dt = \int 2\,dt = 2t + C_1 \]
\[ \begin{aligned} v &= \int a\,dt \\ &= \int 2\,dt \\ &= 2t + C_1 \end{aligned} \]

\(v(0) = -6.0\) より \(C_1 = -6.0\)。よって \(v = 2.0t - 6.0\)。

(2)位置

(1) の速度をさらに \(t\) で積分する。

\[ x = \int v\,dt = \int (2t - 6)\,dt = t^2 - 6t + C_2 \]
\[ \begin{aligned} x &= \int v\,dt \\ &= \int (2t - 6)\,dt \\ &= t^2 - 6t + C_2 \end{aligned} \]

\(x(0) = 5.0\) より \(C_2 = 5.0\)。よって \(x = t^2 - 6.0t + 5.0\)。

(3)\(x = 0\) となる時刻

(2) の式で \(x = 0\) とおいて因数分解する。

\[ t^2 - 6t + 5 = (t - 1)(t - 5) = 0 \qquad\Rightarrow\qquad t = 1.0,\ 5.0 \ \text{s} \]
\[ \begin{aligned} t^2 - 6t + 5 &= (t - 1)(t - 5) \\ &= 0 \\ \Rightarrow\ t &= 1.0,\ 5.0 \ \text{s} \end{aligned} \]

はじめは負の向きに動いて 1.0 s で原点を通り，3.0 s で折り返して，5.0 s に再び原点を通る。

(1)\(v = 2.0t - 6.0\)〔m/s〕
(2)\(x = t^2 - 6.0t + 5.0\)〔m〕
(3)1.0〔s〕と 5.0〔s〕

練習問題③

右図は，\(x\) 軸上を運動する物体の速度 \(v\)〔m/s〕と時刻 \(t\)〔s〕の関係を表している。物体は，時刻 \(t = 0\)〔s〕のとき，位置を \(x = 0\)〔m〕とする。

  1. \(0 \leqq t < 1.0\)，\(1.0 \leqq t < 3.0\)，\(3.0 \leqq t \leqq 5.0\)〔s〕のときの物体の速度 \(v\) を \(t\) を用いてそれぞれ表せ。
  2. \(0 \leqq t < 1.0\)，\(1.0 \leqq t < 3.0\)，\(3.0 \leqq t \leqq 5.0\)〔s〕のときの物体の位置 \(x\) を \(t\) を用いてそれぞれ表せ。
  3. 物体の位置 \(x\)〔m〕と時刻 \(t\)〔s〕の関係を表すグラフを (2) を参考にして示せ。
  4. 物体の加速度 \(a\)〔m/s²〕と時刻 \(t\)〔s〕の関係を表すグラフを示せ。
解説

グラフの形が変わるところで，①\(0 \leqq t < 1\)，②\(1 \leqq t < 3\)，③\(3 \leqq t \leqq 5\) の3つの区間に分けて考える。

(1)速度

各区間は直線なので，傾きと切片を読む（③は \(t\) 軸との交点 (5, 0) を通る）。

  • ① 傾き 1，切片 0　→　\(v = t\)
  • ② 傾き 0（一定）　→　\(v = 1.0\)
  • ③ 傾き \(-\dfrac{1}{2}\)，(5, 0) を通る　→　\(v = -\dfrac{1}{2}(t - 5) = -0.50t + 2.5\)

(2)位置

各区間の速度を積分する。積分定数はその区間のはじめの位置（前の区間の終わりの位置）で決めるのがポイント。

① \(x = \displaystyle\int t\,dt = \frac{1}{2}t^2 + C_1\)。\(x(0) = 0\) より \(C_1 = 0\)。　\(x = \dfrac{1}{2}t^2\)

② \(x = \displaystyle\int 1\,dt = t + C_2\)。①の式から \(x(1) = \dfrac{1}{2}\) なので \(\dfrac{1}{2} = 1 + C_2\)，\(C_2 = -\dfrac{1}{2}\)。　\(x = t - 0.5\)

③ \(x = \displaystyle\int \left(-\frac{1}{2}t + \frac{5}{2}\right)dt = -\frac{1}{4}t^2 + \frac{5}{2}t + C_3\)。②の式から \(x(3) = \dfrac{5}{2}\) なので

\[ \frac{5}{2} = -\frac{9}{4} + \frac{15}{2} + C_3 \qquad\Rightarrow\qquad C_3 = -\frac{11}{4} \]
\[ \begin{aligned} \frac{5}{2} &= -\frac{9}{4} + \frac{15}{2} + C_3 \\ \Rightarrow\ C_3 &= -\frac{11}{4} \end{aligned} \]

よって　\(x = -0.25t^2 + 2.5t - 2.75\)

(3)\(x\)-\(t\) グラフ

(2) の式から \(x(1) = 0.5\)，\(x(3) = 2.5\)，\(x(5) = -\dfrac{25}{4} + \dfrac{25}{2} - \dfrac{11}{4} = 3.5\) m。①は下に凸の放物線，②は直線，③は上に凸の放物線で，\(t = 5\) で止まる（その後は 3.5 m のまま）。

(4)\(a\)-\(t\) グラフ

各区間の速度を微分する（\(v\)-\(t\) グラフの傾き）。①\(a = 1.0\)，②\(a = 0\)，③\(a = -0.50\) m/s²。

(1) \(0 \leqq t < 1.0\)\(v = t\)
(1) \(1.0 \leqq t < 3.0\)\(v = 1.0\)
(1) \(3.0 \leqq t \leqq 5.0\)\(v = -0.50t + 2.5\)
(2) \(0 \leqq t < 1.0\)\(x = \dfrac{1}{2}t^2\)
(2) \(1.0 \leqq t < 3.0\)\(x = t - 0.5\)
(2) \(3.0 \leqq t \leqq 5.0\)\(x = -0.25t^2 + 2.5t - 2.75\)
